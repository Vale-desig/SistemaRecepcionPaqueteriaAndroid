# Sistema de Recepción de Paquetería Android

## Descripción
Aplicación móvil desarrollada en Android Studio para apoyar la gestión de recepción, consulta, registro y entrega de paquetes en una unidad residencial.

## Objetivo
Facilitar el manejo de la información de los paquetes y organizar las actividades relacionadas con su recepción y entrega.

## Tecnologías utilizadas
- Android Studio
- Java
- XML
- Android SDK
- Gradle
- Spring Boot (backend del proyecto)
- MySQL (base de datos del sistema)

## Módulos desarrollados
- Inicio de sesión.
- Menú principal.
- Consulta de paquetes.
- Registro de paquetes.
- Entrega de paquetes.
- Cierre de sesión

## Estado del proyecto
Se desarrollaron las interfaces y funciones básicas de navegación y validación de formularios. La integración de la aplicación móvil con el backend y la base de datos está pendiente de validación.
